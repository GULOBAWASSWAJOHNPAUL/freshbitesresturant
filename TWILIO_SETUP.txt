Fresh Bites SMS and WhatsApp notifications

The forms run through PHP, so use the site through XAMPP/Apache (for example,
http://localhost/freshbitesresturant/), not by opening the HTML files directly.

1. In Twilio, find your Account SID and Auth Token. Enable an SMS sender that
   can send to Uganda, and set up an approved WhatsApp sender.
2. Create and get approval for a WhatsApp content template with this body:

   Fresh Bites: New {{1}} from {{2}} ({{3}}). Details: {{4}}

   Copy the template's Content SID (starts with HX). For WhatsApp Sandbox
   testing, the recipient must first join the sandbox. Production messages
   require an approved sender and template.
3. Set these Windows user environment variables to the values from your
   Twilio account. Do not put credentials in website files:

   TWILIO_ACCOUNT_SID
   TWILIO_AUTH_TOKEN
   TWILIO_SMS_FROM
   TWILIO_WHATSAPP_FROM
   TWILIO_WHATSAPP_CONTENT_SID

   TWILIO_SMS_FROM is the Twilio SMS sender in +countrycode format.
   TWILIO_WHATSAPP_FROM is the Twilio WhatsApp sender in
   whatsapp:+countrycode format. Restart the XAMPP Control Panel and Apache
   after adding the variables so Apache can read them.

4. Confirm PHP's cURL extension is enabled in the XAMPP PHP configuration.
   Then test both a reservation and an order request. Provider charges and
   WhatsApp/SMS delivery restrictions depend on your Twilio account setup.

The order form collects a request only; it does not take payment or
automatically confirm stock, delivery, or the final price.
